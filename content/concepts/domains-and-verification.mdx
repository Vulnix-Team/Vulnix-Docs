---
title: Domains & Verification
description: How to add a Blackbox target and prove you actually own it.
---

A domain has to be verified before it can be used as a Blackbox target or attached to a Whitebox
scope as a combined target — verification is what gates whether a run against it is allowed to
start at all.

## Adding a domain

From **Domains**, add the domain you want to test. It starts in an unverified state — nothing can
be run against it yet.

![Verifying domain ownership](/docs-images/domain-verification.png)

## Verifying ownership

<Tabs items={['DNS TXT record', 'Uploaded file', 'Meta tag', 'Cloudflare / Vercel (automatic)']}>

<Tab value="DNS TXT record">

Add a TXT record with the name and value Vulnix gives you to your domain's DNS zone, then click
**Check now**. DNS changes usually show up within a few minutes. Works regardless of who hosts
your DNS — the most portable option if you're not on Cloudflare or Vercel.

</Tab>

<Tab value="Uploaded file">

Upload a file to the address Vulnix shows (`https://<your domain>/.well-known/vulnix-verify-….txt`),
containing only the token shown. The domain page has the full address, a link to open it and the
file to download. Useful when you control the webserver directly but not the DNS zone.

</Tab>

<Tab value="Meta tag">

Add a meta tag to your site's homepage `<head>`. The fastest option if you can push a small
markup change without a deploy pipeline.

</Tab>

<Tab value="Cloudflare / Vercel (automatic)">

<Callout title="No copy-pasting required">
  Connect the provider via OAuth and Vulnix creates the DNS record for you directly — the
  domain verifies itself, no manual DNS step at all.
</Callout>

When your domain's DNS is at Cloudflare or Vercel, the domain page, the welcome tour and the
pentest wizard all offer **Connect Cloudflare** (or **Connect Vercel**). Approve once on their
site and you come back to the same place; Vulnix adds the record and checks it. If DNS takes a
moment to show it, Vulnix keeps checking for a few minutes. Once connected, the same button reads
**Add record and verify** for every domain in the workspace whose DNS is there.

Connected providers are listed under **Integrations**, where you can disconnect them. Records
already added stay in your DNS.

</Tab>

</Tabs>

## After verification

- The domain's page offers **Start a pentest**, which opens the pentest wizard with the domain
  already in Targets, and **Add a test user**.
- The domain becomes selectable as a Blackbox target in the pentest wizard.
- You can optionally save test-user credentials against it for authenticated testing — see
  [Scoping a Run](/concepts/scoping-a-run).
- It becomes eligible to attach to a Whitebox scope as a combined target (the $225 price point —
  see [Blackbox vs. Whitebox](/concepts/blackbox-vs-whitebox)).
