The API has no `v1`/`v2` in its path (see [Conventions](/api/conventions#base-url)): existing
fields and endpoints don't change shape under you, so there is nothing to migrate between. This
page is the append-only record of what got added, for anyone who wants to know what's new
without diffing the reference by hand.

<Callout type="info" title="Nothing here is ever a breaking change">
  A breaking change to an existing field or endpoint would be a bug, not an entry on this page.
  Everything below is additive: a new endpoint, a new scope, a new event.
</Callout>

## 2026-10

- **New plans.** `GET /billing/status` adds `pricing`, `pentests` (`{ left }`) and `pr_reviews`
  (`{ used, included, resets_at }`); each plan adds `pricing`, `monthly_pentests` and
  `monthly_pr_reviews`. `GET /runs/{run_id}` adds `pentests_charged`. A `credits_exhausted` error on
  Free, Builder, Startup and Pro carries `details.unit: "pentest"`. See [Billing](/api/billing).
- **Whitebox on every plan.** `POST /scopes` no longer returns `whitebox_requires_paid_plan`.
- **New error code** `automation_requires_startup_plan` when Free or Builder creates an API token or
  webhook endpoint. Existing tokens and endpoints are unaffected.

## 2026-09

- **Webhooks.** Subscribe an endpoint in the console to get a signed `POST` the moment a run
  finishes, a PR review reaches a verdict, or a finding changes — instead of polling. See
  [Webhooks](/api/webhooks).
- **API tokens.** Personal and service tokens, scoped per resource (`runs:read`,
  `findings:write`, and so on) and capped by the creator's role. See
  [Authentication](/api/authentication).
- **Public OpenAPI spec.** The full token-reachable surface is now published as
  [`openapi.json`](/openapi.json) for Postman/Insomnia import or client generation.
